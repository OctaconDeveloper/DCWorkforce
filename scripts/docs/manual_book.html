Part II: Registration & Member Search

2. Registration & Duplicate Rejection Safeguard

To ensure database integrity and eliminate duplicate profiles, all new registration attempts are validated against existing records:

🛡️
Automatic Phone Number Collision Check:
If a registration form is submitted containing a phone number that is already registered to an active worker or pending approval, the submission is immediately rejected with a detailed notification identifying the existing worker profile.
🟢 WhatsApp • Duplicate Registration Rejection
❌ *REGISTRATION REJECTED: PHONE ALREADY REGISTERED* ──────────────────────────── A church worker record already exists with the phone number *08012345678*: • *Full Name:* Brother David Eze • *Department:* MEDIA (Sound) • *Role:* Member • *Status:* Active ✅ 💡 *Note:* If you need to update your details or change departments, please contact your Head of Department (HOD) or Church Administrator.

Church Administrators, Department Heads (HODs), and Unit Heads can search for registered workforce members across multiple parameters (Name, Phone Number, Unit, Role, Address).

4. Complete Command Catalog

Command Role Syntax / Example Description
